HTML stands for HyperText Markup Language. It is the universal standard language used to create, structure, and display pages on the World Wide Web.
Originally created by Tim Berners-Lee in the early 1990s,
HTML serves as the foundational skeleton of virtually every website you visit.
Unlike programming languages, HTML is a markup language. It does not execute logic or calculations;
instead, it uses a system of text annotations called tags to tell a web browser exactly how to display content like text, images, and links
